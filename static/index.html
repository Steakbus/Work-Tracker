    Nothing showed up? Check these, in order
    1. Allow the site in the browser: click the icon left of the address bar → Notifications → Allow (Firefox: Permissions; Safari: Settings → Websites → Notifications).
    2. Allow the browser in macOS: System Settings → Notifications → (your browser) → Allow notifications on, style Banners or Alerts.
    3. Focus / Do Not Disturb must be off (Control Center).
    4. Keep one tracker tab open (it can be in the background). Without a tab you get a plain macOS notification instead.
    5. Then press Send test notification again.
